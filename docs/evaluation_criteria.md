# 熊谷市議会 議員・議会評価の基準と方法論

本プロジェクトは、公開情報(会議録・審議結果・名簿など)に基づいて、
熊谷市議会の「議員個人の議会活動」と「議会全体の審議」を継続的に観察・評価するための枠組みである。

## 1. 評価の原則

1. **公開情報のみを用いる** — 会議録、審議結果、議員名簿、議会公式サイト等、誰でも検証できる情報だけを使う。
2. **基準の透明性** — 指標の定義とルーブリックを本ドキュメントで公開し、全議員に同一基準を適用する。
3. **定量と定性の分離** — 機械的に数えられる指標(発言量・回数・賛否)と、AIによる質の評価(具体性・提案性など)を明確に区別して提示する。
4. **AI評価は「参考意見」** — AIによるスコアは会議録テキストに基づく一つの読み方であり、断定的な人物評価ではない。必ず根拠引用を添え、読者が検証できるようにする。
5. **限界の明示** — 本会議の会議録は議員活動の一部でしかない。委員会での質疑、会派内の調整、地域活動、相談対応などは反映されない。「発言が少ない=働いていない」とは限らない。
6. **公平性・名誉への配慮** — 所属会派・政党・思想信条は評価対象にしない。改善点は建設的な表現で記述し、名誉毀損にあたる断定表現を避ける。

## 2. 議員個人の評価

### 2.1 定量指標(metrics.py が自動算出)

| 指標 | 定義 | 備考 |
| --- | --- | --- |
| 発言回数 | 本会議での発言(議事進行発言を含む)の回数 | 会議録の発言者マーカー単位 |
| 発言文字数 | 発言本文の文字数(空白除く) | 量の指標であり質は含まない |
| 一般質問回数 | 一般質問を含む会議で発言した会議数 | 通告ベースではなく会議録ベース |
| 発言した会議数 | 解析対象のうち発言があった会議の数 | |
| 議案への賛否 | 公表されている議案ごとの賛否 | 賛否CSVを与えた場合のみ |

### 2.2 定性ルーブリック(AI評価・各1〜5点)

一般質問・質疑・討論のテキストを対象に、以下の5基準で採点する。3点が「標準的な水準」。

| 基準 | 1点の目安 | 3点の目安 | 5点の目安 |
| --- | --- | --- | --- |
| 具体性 (specificity) | 一般論・伝聞のみ | 一部に統計や事例を引用 | 独自に調べた数字・現場の事実・比較データに基づく |
| 政策提案性 (proposal) | 現状の批判・要望のみ | 方向性の提案がある | 財源・先行事例を含む実行可能な対案を提示 |
| 追及・検証力 (follow_up) | 答弁をそのまま受け入れて終了 | 再質問で一部を掘り下げ | 答弁の矛盾・期限を具体的に詰め、次回の確認まで予告 |
| 市民関連性 (citizen_relevance) | 誰の課題か不明確 | 対象層は明確 | 対象と影響規模が数字で示され、優先順位の説明がある |
| 論点明確さ (clarity) | 質問の趣旨が不明瞭 | 概ね明確 | 論点が構造化され、答弁側が答えるべき点が明確 |

**運用ルール**

- 各スコアには会議録からの引用(根拠)を必ず添える。
- 発言量が少ない議員(既定: 400字未満)は採点しない(材料不足)。
- スコアは「その期間の会議録に現れた発言」への評価であり、議員の能力の総合評価ではない。

## 3. 議会全体の評価

### 3.1 定量指標

| 指標 | 定義 | 見方 |
| --- | --- | --- |
| 発言議員率 | 発言した議員 / 名簿上の議員 | 低い場合、本会議での議論が一部に偏っている可能性 |
| 発言量ジニ係数 | 議員間の発言文字数の偏り(0=均等、1=独占) | 高いほど少数の議員に発言が集中 |
| 議員/執行部の発言比率 | 発言数・文字数の比較 | 答弁偏重か議員主導かの目安 |
| 全会一致率 | 賛否が分かれなかった議案の割合 | 高すぎる場合、議案審議が形式化している可能性(ただし議案の性質にもよる) |

### 3.2 定性評価(AI)

- **審議の実質性**: 質問と答弁がかみ合っているか。「検討します」で終わる答弁への追及があるか。
- **答弁の質**: 執行部が数字と期限を伴って答えているか。
- **注目すべき議論**: 政策的に重要なやり取りの抽出。
- **改善提案**: 議会運営・審議の質の向上につながる建設的な提案。

### 3.3 開かれた議会チェックリスト(手動確認)

会議録からは判定できないため、公式サイト等で確認して記録する(早稲田大学マニフェスト研究所「議会改革度調査」等の観点を参考)。

- [ ] 議案に対する議員別の賛否を公開している(熊谷市議会は審議結果ページで公開)
- [ ] 本会議の中継・録画配信がある
- [ ] 委員会の会議録・中継が公開されている
- [ ] 議会報告会・意見交換会を開催している
- [ ] 政務活動費の収支・領収書を公開している
- [ ] 議員間の自由討議の仕組みがある
- [ ] 通年議会または柔軟な会期設定を行っている

## 4. 運用手順

1. `fetch_minutes.py` で対象期間の会議録を取得(または手動で `data/minutes/` に保存)
2. 公式サイトの名簿PDFから `data/members.json` を作成・更新
3. 審議結果ページから賛否を `data/votes.csv` に転記
4. `run_evaluation.py` でレポート生成(`--ai` で定性評価を追加)
5. レポートの内容を人間がレビューし、引用の正確さを確認してから公開する

## 5. 法的・倫理的配慮

- 会議録の利用は出典を明示し、各サイトの利用規約に従う。
- 評価の公表にあたっては、事実(定量指標・引用)と意見(AI所見)を明確に区別する。
- 選挙運動期間中の公表は公職選挙法上の扱いに注意し、特定候補の当選・落選を目的とする表現をしない。
- 議員本人から誤りの指摘があった場合の訂正手順をあらかじめ用意する。
